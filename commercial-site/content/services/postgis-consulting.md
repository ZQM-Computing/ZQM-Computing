Spatial database performance depends on schema design, query behavior, data distribution, geometry complexity and operational constraints—not simply whether a spatial index exists.

## How do you investigate a slow PostGIS query?

Review PostgreSQL/PostGIS versions, representative execution plans, query predicates, geometry types and SRIDs. Measure observed behavior and evaluate indexing or query changes on representative workloads before production rollout.

## What is included in migration discovery?

A defined migration discovery can inventory spatial tables, identify key/CRS/geometry mismatches, plan record reconciliation and document recovery and cutover acceptance conditions. Actual production migration requires separate authorization.
