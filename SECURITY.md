# Security Policy

Report vulnerabilities to [zqmcomputing@gmail.com](mailto:zqmcomputing@gmail.com).

## Scope

- All ZQM Computing public repositories
- ZQM Computing infrastructure and tooling

## Reporting

- **Email**: [zqmcomputing@gmail.com](mailto:zqmcomputing@gmail.com)
- **GitHub Security Advisory**: Use the "Security" tab on GitHub
- Please do NOT open public issues for security vulnerabilities

## What to Expect

- Acknowledgment within 48 hours
- Assessment and severity classification within 5 business days
- Coordinated disclosure timeline agreed upon with reporter

## Supported Versions

| Version | Supported |
|---------|-----------|
| latest  | Yes       |
| < latest| No        |
